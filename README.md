# 卒論のためのAIスキル一式

ChatGPT（Codex）で論文を探して集め、日本語の資料にし、卒論の文章とレジュメを作るためのセット。
地質系の学部生向けに作った。Windows で動く。

## 入れ方

```
→ このページの緑の「Code」ボタン →「Download ZIP」
→ ダウンロードしたZIPを右クリック →「すべて展開」
→ 展開したフォルダの setup.cmd をダブルクリック
→ Git を入れるときに Windows の許可の画面が出たら「はい」を押す
→ 黒い画面に「終わりました」と出たら、何かキーを押して閉じる
```

ネットにつないだ状態で実行する。ソフトのダウンロードに数分かかる。
何度実行しても、自分のファイルは上書きされない。入っているソフトは飛ばす。
新しい版が出たら、同じ手順でもう一度実行すれば、スキルだけが新しくなる。

## 入るもの

| 種類 | 中身 |
|---|---|
| ソフト | Python 3.13（pymupdf・pillow 込み）、VS Code（日本語化込み）、Git |
| 作業フォルダ | `C:\dev\卒論\`。研究テーマを書く `AGENTS.md`、論文の台帳 `文献一覧.md`、`論文\`、`レジュメ\`。デスクトップに、このフォルダを開くショートカット「卒論」 |
| 共通の決まり | ユーザーフォルダの `.codex\AGENTS.md`。どのフォルダでも守る決まり |
| スキル | ユーザーフォルダの `.agents\skills\`。下の4つ |

| スキル | できること |
|---|---|
| `paper` | 論文を探す、DOIから書誌を引く、PDFから解説・AIメモ・日本語訳を作る、地質学雑誌の書式で引用文献リストを作る |
| `paper-writing` | 卒論・予稿・レポートを地質学の論文の文体で書く、直す |
| `doc-design` | ゼミのレジュメやまとめ資料をHTMLで作る（左に目次、中央に解説、右に補足） |
| `irasutoya` | 資料にいらすとやの挿し絵を入れる |

## 最初にやること

`C:\dev\卒論\AGENTS.md` を VS Code で開き、「研究テーマ」の欄を自分の卒論に書き換える。
論文を探すときの判断と、論文ごとの位置づけは、この欄を基準にする。

## 使い方

ChatGPT（Codex）で `C:\dev\卒論` を開いて、普通に頼む。

- 「〇〇に関する論文を10本探して」
- 論文PDFを渡して「この論文を読めるようにして」
- 「台帳の続きから」
- 「卒論で引用した論文の引用文献リストを作って」
- 「来週のゼミのレジュメを作って」

論文は1本1フォルダで `C:\dev\卒論\論文\` に置かれる。フォルダ名の頭が進み具合を表す。

| フォルダ名の頭 | 意味 |
|---|---|
| `未入手_` | 論文PDFがまだ無い。文献一覧.md のメモ列に理由がある |
| `未処理_` | 論文PDFはある。解説はまだ |
| `処理済み_` | 解説・AIメモ・日本語訳まで作った |

`文献一覧.md` は、VS Code で開いて右上のプレビューのボタンを押すと表で見える。
HTML の資料は、デスクトップの「卒論」からフォルダを開き、ダブルクリックでブラウザに出す。

## 注意

- 大学の契約で入手した論文PDFを、GitHub など公開の場所に置かない
- 日本語訳は自分用。人に配らない
- いらすとやの絵は、いらすとやの利用規約の範囲で使う
