1. 見出し

本文。行の長さは34字で固定してあるので、ここを広げない。 中央の列が広くなっても行長は変わらず、余った幅は右の札に回る。 強調は太字だけで作る。リンクは藍＋下線で示す。

見出しに data-fig="c1" を付けると、この章を読んでいる間だけ 右の data-card="c1" の札が出る。付けなかった章では、直前の札が残る。

小見出し

札は data-card で結ぶ。中身は図でなくてよい。 表・確認問題・用語の一覧も同じ枠に入る。 右は補足で、本文は中央に全部書く。 右の札を全部消しても、中央だけで話が通じるようにする。

置くものが無い章には札を作らない。見出しに data-fig を付けなければ、直前の札が残る。

2. 見出し

番号の並びは data-label の文字で作る。押すと本文がその章へ飛ぶ。 ホバーで出る説明は data-title に書く。

「固定」を押している間は、スクロールしても札が替わらない。 図を触りながら別の章を読むときに使う。固定中は右の縁に藍の線が出る。

注意 有色の callout はこの1種類だけ。ラベル文字を必ず置く。 札の中でも同じで、色だけに意味を持たせない。

3. 見出し

data-always を付けた札は切り替わらず、ずっと出たままになる。 年表・全体図・用語の一覧のように、どの章でも横に置いておきたいものに使う。

その中の項目に data-since="s2" を付けると、その章を過ぎるまで出ない。 読み進めるほど増えていく一覧になる。一度出た語が後の章でも出てくる分野で効く。

4. 見出し

右には図や写真も置ける。本文で「図4」と書いて説明し、図そのものは右の札に置く。 本文を読みながら、スクロールで流れていかない図を横で見られる。

ここまでが3カラムの説明。中身を差し替えて使う。 CSS は書き換えない。足りない型は既存の型を複製する。
