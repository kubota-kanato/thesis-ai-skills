# いらすとや素材の取得

**図がほしいときは、自分で `<svg>` を書かない。実物のイラストを拾って貼る。**
自作の線画は手間のわりに伝わらないし、読み手がイメージをつかむ助けにならない。

---

## 1. サイト内検索は使えない。フィード API を叩く

いらすとやのサイト内検索（`/search?q=...`）は JavaScript で描画される。
HTML を取得しても画像 URL が入っていないので、スクレイピングしても空振りする。

**Blogger のフィード API** なら、素材名と画像 URL が JSON でそのまま返る。

```
https://www.irasutoya.com/feeds/posts/default?q=<検索語>&alt=json&max-results=25
```

各エントリの `content.$t` の中にある `blogger.googleusercontent.com/img/...` が画像 URL。
パスの `/s800/` や `/s1600/` を `/s400/` に書き換えるとサイズが落ちる（印刷用の挿し絵はこれで十分）。

この操作は `いらすとや.py` に入っている。**curl を直接叩かず、これを使う。**

---

## 2. コマンド

スクリプトは `~/.agents/skills/irasutoya/いらすとや.py`。どこから叩いてもよい。

```powershell
python "$env:USERPROFILE\.agents\skills\irasutoya\いらすとや.py" 検索 縄文 土器 竪穴住居
```

| コマンド | すること |
|---|---|
| `検索 <語> <語> ...` | フィード API を叩き、ヒットした素材を `_索引.tsv` に貯める |
| `索引 <語>` | 通信せず、**貯めた索引の中だけ**を引く。まずこれを試す |
| `取得 <出力先> <slug> ...` | 索引から引いて `<出力先>/<slug>.png` に落とす |

```powershell
cd C:\dev\<プロジェクト>
python "$env:USERPROFILE\.agents\skills\irasutoya\いらすとや.py" 取得 img doki_joumon doguu himiko
```

- 出力先は**呼んだ場所からの相対パス**
- 既定は `s400`。大きめが要るときだけ `--s800` を足す
- `_索引.tsv`（slug・素材名・URL）は**スクリプトの隣に置かれ、プロジェクトをまたいで共有される**。叩くほど育つので、まず `索引` で当たりを探すと通信せずに済む
- 続けて API を叩くと弾かれて0件が返るため、スクリプト内で1.5秒あけてある

## 3. 探すときのコツ

- **歴史上の人物・有名人は `似顔絵` シリーズにある。** 聖徳太子・卑弥呼・小野妹子・中大兄皇子などは揃っている
- 抽象語（「身分」「争い」「格差」）より、**具体物（「高床倉庫」「埴輪」「投票」）**のほうが当たる
- 出てこないときは言い換える。「貧富の差」→「格差」、「まつり」→「神様」
- slug は URL 末尾のファイル名。`nigaoe_` は似顔絵、`doki_` は土器、`building_` は建物、と接頭辞で系統が分かる

---

## 4. 利用条件

- **商用のデザインに使う場合、1つの制作物につき20点まで無料**（同じ素材の重複は1点と数える）。21点以上を商用で使うなら有償対応になる
- **非商用（個人利用・販売しない配布物）には点数の上限がかからない。** 必要なだけ入れてよい
- 点数を問わず、**素材を主体とした再配布・販売はしない**（素材集めたものそれ自体を売らない）
- 出典表記は義務ではない。紙面に URL を載せたくない資料では、`_出典メモ.md` のような配らないファイルに控える

商用で配るものを作るときは、使用点数を数えて20点以内に収めるか、いらすとやの規約を確認すること。

## 5. 単体 HTML に焼き込む

画像を `<img src="img/xxx.png">` で参照したままだと、HTML 1枚を渡しても絵が出ない。
配布物にするときは **base64 で焼き込んで単体ファイルにする**。

```python
import base64, io, os, re

def 焼き込む(html, img_dir):
    def 置換(m):
        path = os.path.join(img_dir, m.group(1))
        b64 = base64.b64encode(io.open(path, 'rb').read()).decode('ascii')
        return 'src="data:image/png;base64,%s"' % b64
    return re.sub(r'src="IMG:([^"]+)"', 置換, html)
```

編集用の正本では `src="IMG:<ファイル名>"` のプレースホルダで書いておき、ビルド時に置換する。
**焼き込み後の HTML は手で直さない**（次のビルドで消える）。

s400 の PNG は1枚 30〜150KB 程度。20枚入れると HTML が数MB になるが、ブラウザでは問題なく開く。
