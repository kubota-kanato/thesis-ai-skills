# DOIから書誌を引き、文献一覧と引用文献リストを作る

書誌（著者・年・題名・誌名・巻・ページ）を手で写さない。必ず `refs.py` で引く。
自分の記憶やWeb検索の結果から書誌を書くと、著者名や巻・ページを間違える。

スクリプト：`%USERPROFILE%\.agents\skills\paper\tools\refs.py`。Python の標準ライブラリだけで動く。料金はかからない。

## 書誌を引いて保存する

```powershell
python "$env:USERPROFILE\.agents\skills\paper\tools\refs.py" fetch 10.5575/geosoc.2016.0021 10.1029/2010JB007617
```

- DOI は `https://doi.org/...` や `doi:...` の形のまま渡してもよい
- `C:\dev\卒論\論文\` に論文フォルダ `未入手_{題名}` を作り、その中に `書誌.json` を置く
- 題名から `\ / : * ? " < > |` を外し、40字で切る。英語の題名は単語の途中で切らない
- 同じ DOI の `書誌.json` がすでにどこかの論文フォルダにあれば、新しく作らない
- 最後に `C:\dev\卒論\文献一覧.md` を作り直す

## 文献一覧.md を作り直す

PDFを置いたとき、解説を作り終えたとき、論文フォルダを消したときは、必ず作り直す。

```powershell
python "$env:USERPROFILE\.agents\skills\paper\tools\refs.py" index
```

- 状態（`未入手`・`未処理`・`処理済み`）は、フォルダの中の `論文.pdf` と `解説.html` の有無で決まる
- フォルダ名の頭の状態も、このとき中身に合わせて付け替わる。題名の部分は残る
- フォルダ・状態・著者・年・題名・DOI の列は作り直される
- 位置づけとメモの列は、前の文献一覧.md から DOI で引き継ぐ
- 位置づけには `支持する`・`反する`・`手法の参考`・`背景` のどれかと、一言の理由を書く
- DOI の無い文献の行は、手で足す。作り直しても消えずに表の最後に残る

## 引用文献リストを作る

```powershell
python "$env:USERPROFILE\.agents\skills\paper\tools\refs.py" list 10.5575/geosoc.2016.0021 10.1029/2010JB007617
python "$env:USERPROFILE\.agents\skills\paper\tools\refs.py" list --all -o 引用文献.md
```

- `--all` は論文フォルダにある書誌すべてを使う。卒論で引用したものだけにするなら、DOI を並べて渡す
- `list` に渡した DOI のうち、論文フォルダに無いものは、その場で書誌を引いてリストに入れる。フォルダは作らない
- 出力は2つの節になる
  - 引用文献：地質学雑誌の細則4の書式で、著者名のアルファベット順に並ぶ
  - 本文中の引用の形：「片桐ほか（2016）」「（片桐ほか，2016）」のように、本文に貼る形
- 既定は Markdown。誌名が `*斜体*`、巻が `**太字**` になる。Word に貼るなら `--text` を付け、Word 側で誌名を斜体、巻を太字にする

日本語の論文は、日本語の書誌のあとに `[ ]` で英語の書誌が付く。地質学雑誌の決まりで、日本語文献には英訳を添えるため。

## 出力のうち、手で確かめる所

スクリプトは確かめる所を「確認：」で始まる行に出す。次の3つは必ず見る。

1. 誌名の略記：細則が示す UBC の略記表（https://woodward.library.ubc.ca/research-help/journal-abbreviations/）で調べて置き換える。スクリプトが知っている略記は、地質学雑誌の例に出てくる誌名だけ
2. 題名の大文字：英語の論文の題名は、文頭と固有名詞だけを大文字にする。原典が Title Case なら直す
3. 英語の題名が無い日本語論文：`【英語の題名が無い】` と出る。英訳して末尾に `*` を付け、リストの最後に「*English translation from the original written in Japanese」と書く

書籍と本の章は、総ページ数や出版社の所在地が取れないことがある。「確認：」に出たものを手で足す。

## DOI が無い文献

古い論文、地質図幅、講演要旨、学位論文には DOI が無いことが多い。
その文献は手で書く。書式は地質学雑誌の細則4（投稿編集出版規則の細則）の例にならう。
書誌は、出版社・J-STAGE・CiNii の書誌画面を開いて写す。推測で埋めない。

授業や別の学会誌が別の書式を指定していれば、出力を元にその書式へ直す。
