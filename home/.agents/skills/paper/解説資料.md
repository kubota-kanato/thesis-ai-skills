# 論文PDFから、解説・AIメモ・日本語訳を作る

作業場所は `C:\dev\卒論\論文\`。下のコマンドはすべて、このフォルダで実行する（`cd C:\dev\卒論\論文`）。
`{フォルダ}` は論文フォルダの名前（例：`未処理_浦幌層群の凝灰岩のU-Pb年代`）に置き換える。空白を含むので `"` で囲む。

## できあがる資料は3つ

| ファイル | 読む人 | 中身 |
|---|---|---|
| `解説.html` | 本人 | 目次・解説・原典の図の3列。要約、前提知識、手法、図の読み方、卒論での位置づけ |
| `AIメモ.md` | 後でAIが読み返す | 要点、数値、ページ・図表番号、位置づけ。型は `型\AIメモ.md` |
| `日本語訳.md` と `日本語訳.html` | 本人が原文と照らす | 章・節の構成を保った日本語版 |

HTMLは画像をbase64で埋め込む。ファイル1つをコピーしても図が出て、ネット接続も要らない。
`AIメモ.md` は、卒論の考察や引用文献を書くときに、PDFを読み直さずに済むように作る。

## 守ること

- 図は必ず論文PDFから切り出す。matplotlib・mermaid などで描き起こさない
- キャプションは全訳して図の下に置き、出典（著者・年・雑誌・図番号）を書く
- 逐語の全文訳は作らない。出版社の論文を丸ごと複製することになるため
- 日本語訳は章・節の構成をそのまま保つ。節を飛ばさず、数値・試料名・対比の根拠まで日本語で書き起こす
- 日本語訳は本人用。人に配らない
- 訳注は `> ※ ...` で入れる
- 専門用語は初出で「和訳 (原語)」と併記する
- 測定の結果と、著者の解釈を分けて書く

## 解説.html は doc-design の読む資料モードで作る

`doc-design` スキルの `read.html` を丸ごとコピーし、中身だけ差し替える。CSSは書き換えない。
右の欄に論文の図を出す仕組み（`tools\figpane.html`）は、`bake.py` と `md2html.py` が差し込む。

画面幅1280px以上では「左に目次｜中央に解説｜右に論文の図」の3列になる。
本文は中央に全部書く。右の欄は、本文中の `<figure>` を自動で移して出すだけで、自分で書く場所ではない。
条件は2つ。

- 図は `<figure>` に入れ、`<figcaption>` を「図 N.」で始める
- 本文では図を「図 N」と書く。自動でリンクになる

挿し絵は `irasutoya` スキルで10枚前後落とす。絵に情報を担わせない。絵が出なくても意味が通るように書く。

`解説.html` の節の並び：

1. 3行でいうと
2. 書誌情報の表
3. この研究が解こうとした問題
4. 前提知識の補足（読者は分野外だと思って書く）
5. 手法の核心と、なぜそれが効くのかの直感的な説明
6. 現場と試料
7. 結果
8. 図の読み方（主要な図を1枚ずつ、どこをどう見るか）
9. 卒論での位置づけ（`支持する`・`反する`・`手法の参考`・`背景` のどれかと、その理由）
10. 押さえどころのまとめ
11. 限界と注意点

## 手順

必要なもの：Python と `pymupdf` `pillow`。無ければ入れてから始める。

```
論文.pdf の全文を読む
→ 図を切り出して目で確かめる
→ 挿し絵を落とす
→ 図を縮小する
→ 解説_src.html を書いて 解説.html に焼き込む
→ 日本語訳.md を書いてHTMLにする
→ AIメモ.md を型どおりに書く
→ 長すぎる文を切る
→ 開いて確かめる
→ refs.py index で台帳とフォルダ名を更新する
```

### 1. 全文を読む

```powershell
New-Item -ItemType Directory -Force "{フォルダ}\図", "{フォルダ}\挿し絵", "{フォルダ}\作業\表示用" | Out-Null
python -c "import fitz,io; d=fitz.open(r'{フォルダ}\論文.pdf'); io.open(r'{フォルダ}\作業\全文.txt','w',encoding='utf-8').write('\n'.join(f'===== PAGE {i+1} =====\n'+p.get_text() for i,p in enumerate(d)))"
```

`作業\全文.txt` を最初から最後まで読む。読み終えるまで書き始めない。

### 2. 図を切り出し、`図\図1.png` から通し番号で保存する

`page.get_image_info()` で埋め込み画像の有無と大きさを見る。図は2種類あり、扱いが違う。

- 1枚の画像として埋まっている図（写真、スキャン）は、`fitz.Pixmap(doc, xref)` でそのまま抜く
- ベクタ描画の図（地図、グラフ、柱状図）は、`page.get_text('blocks')` で本文ブロックの位置を調べて図の矩形を割り出し、`get_pixmap(matrix=fitz.Matrix(4,4), clip=...)` で4倍解像度で切り出す

切り出したら必ず縮小版を目で見る。キャプションや隣の段組の巻き込み、図の端の欠けは、見ないと分からない。

### 3. 挿し絵を落とす

```powershell
python "$env:USERPROFILE\.agents\skills\irasutoya\いらすとや.py" 検索 <語> <語>
python "$env:USERPROFILE\.agents\skills\irasutoya\いらすとや.py" 取得 "{フォルダ}\挿し絵" <slug> ...
```

### 4. 図を埋め込み用に縮小する

長辺1500pxのJPEGにする。フル解像度のまま埋め込むとHTMLが数十MBになる。

```powershell
python "$env:USERPROFILE\.agents\skills\paper\tools\webfigs.py" "{フォルダ}"
```

### 5. `作業\解説_src.html` を書き、解説.html に焼き込む

画像は `src="IMG:図1.jpg"`（縮小した図）や `src="IMG:<slug>.png"`（挿し絵）と書く。

```powershell
python "$env:USERPROFILE\.agents\skills\paper\tools\bake.py" "{フォルダ}" 作業\解説_src.html 解説.html
```

`bake.py` は、`data:` 以外の画像参照が残っていればエラーで止まる。

### 6. 日本語訳を書いて、HTMLにも変換する

`{フォルダ}\日本語訳.md` を書く。図は `![図1](図/図1.png)` と書き、次の段落をキャプションにする。

```powershell
python "$env:USERPROFILE\.agents\skills\paper\tools\md2html.py" "{フォルダ}"
```

### 7. AIメモを書く

`型\AIメモ.md` をコピーして `{フォルダ}\AIメモ.md` にし、見出しを省略せずに埋める。

### 8. 読解負荷を測って、長すぎる文を切る

```powershell
python "$env:USERPROFILE\.agents\skills\doc-design\reading-load.py" "{フォルダ}\作業\解説_src.html"
```

`kanji_run` は専門用語で必ず出るので直さない。直すのは `sentence_too_long` のうち、引用文献ではない地の文。

### 9. 開いて確かめる

2本のHTMLをブラウザで開き、図・目次・右の図の欄が動くか見る。外部参照が残っていないことも確かめる。

```powershell
Select-String -Path "{フォルダ}\解説.html" -Pattern 'src="(?!data:)' -AllMatches
```

0件なら完成。

### 10. 台帳とフォルダ名を更新する

```powershell
python "$env:USERPROFILE\.agents\skills\paper\tools\refs.py" index
```

フォルダ名が `処理済み_` に変わる。文献一覧.md の位置づけ列に、解説の9節と同じ位置づけを書く。
