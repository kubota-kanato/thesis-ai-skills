# 論文を探して集め、日本語の資料にする

作業場所は `C:\dev\卒論\`。決まりと研究テーマは `C:\dev\卒論\AGENTS.md` にあるので、先に読む。
スクリプトは `%USERPROFILE%\.agents\skills\paper\tools\` にある。

## 頼まれたことに合う手順書を読んでから始める

| 頼まれたこと | 読む手順書 |
|---|---|
| 論文を探す、PDFを集める | `探す.md` |
| DOIから書誌を引く、文献一覧を直す、引用文献リストを作る | `書誌と引用.md` |
| 論文PDFから解説・AIメモ・日本語訳を作る | `解説資料.md` |

「論文を探して、読めるようにして」のように続けて頼まれたら、上から順に全部やる。

## 置き方

```
卒論/
├── AGENTS.md          ← 研究テーマと決まり
├── 文献一覧.md         ← 論文の台帳。refs.py index が作り直す
├── レジュメ/           ← ゼミ発表のレジュメ
└── 論文/
    └── {状態}_{題名}/   ← 1本1フォルダ
        ├── 書誌.json    ← refs.py が引いた書誌
        ├── 論文.pdf     ← 論文PDFのコピー
        ├── 解説.html
        ├── AIメモ.md
        ├── 日本語訳.md / 日本語訳.html
        ├── 図/          ← 論文PDFから切り出した図
        ├── 挿し絵/
        └── 作業/        ← 中間ファイル
```

## 状態はフォルダの中身で決まる

| 状態 | 中身 |
|---|---|
| `未入手` | 論文.pdf が無い |
| `未処理` | 論文.pdf はある。解説はまだ |
| `処理済み` | 解説.html まで作った |

フォルダ名の頭の状態は、`refs.py index` を実行するたびに中身に合わせて付け替わる。
自分で名前を書き換えない。PDFを置いたときと解説を作り終えたときに、必ず index を実行する。

```powershell
python "$env:USERPROFILE\.agents\skills\paper\tools\refs.py" index
```

## 論文1本ごとに台帳を確定してから次へ進む

10本頼まれても、1本ずつ「入手 → 資料作り → index」を終えてから次に移る。
途中で止まっても、文献一覧.md を見れば続きから再開できる。
「台帳の続きから」と頼まれたら、`未処理` の行から再開する。

## 守ること

- 要旨を読まずに、テーマに関わるかを決めない。要旨だけで優先度を付けない
- 論文の内容を説明するときは、ページ・節・図表番号を添える
- 測定の結果、著者の解釈、自分の推測を分けて書く
- 大学の契約で入手した論文PDFを、GitHub など公開の場所に置かない
